# Домашняя работа базовые конструкции Bash-скриптов

## Описание работы
Данная работа посвящена изучению базовых возможностей командной оболочки Bash (до темы циклов): созданию сценариев, работе с переменными окружения и пользовательскими переменными, выполнению арифметических операций, а также ветвлению условий (`if-then`, `else`, `elif`) с проверкой чисел, строк и файлов.
