# Домашняяработа: Операции с файлами и каталогами в Linux

## 1. Цель работы
Изучение файловой иерархии ОС Linux, классификации типов файлов, принципов работы командного интерпретатора Shell, а также освоение синтаксиса и практическое применение базовых утилит для навигации, создания, просмотра, копирования, перемещения, удаления, фильтрации и поиска файлов и каталогов.
