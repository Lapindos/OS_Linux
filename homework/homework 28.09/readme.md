# Домашняя работа: управление процессами и сигналами в Linux

## 1. Цель работы
Изучение базовых механизмов управления процессами в операционной системе Linux, освоение утилит мониторинга (`top`), планирования (`at`), управления фоновыми задачами (`jobs`, `fg`, `bg`, `nohup`), изменения приоритетов (`nice`, `renice`), а также отправки сигналов завершения и приостановки (`kill`, `killall`).
