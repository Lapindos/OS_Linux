# Домашняя работа: Управление владельцами и правами доступа к файлам в Linux

## 1. Цель работы
Приобретение практических навыков создания учетных записей пользователей в Linux, создания файлов от имени различных пользователей, переназначения владельцев файлов с использованием утилиты `chown`, а также настройки различных уровней прав доступа с помощью утилиты `chmod` и последующей проверки доступа.
