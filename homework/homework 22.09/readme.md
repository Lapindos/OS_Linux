# Домашняя работа: Управление пользователями, группами и правами доступа в Linux

## 1. Цель работы
Приобретение практических навыков администрирования учетных записей в операционной системе Linux: создание новых пользователей и групп (`useradd`, `groupadd`), включение пользователей в группы (`usermod`), разграничение прав доступа к файловой системе (`chmod`, `chown`), а также тестирование прав доступа при переключении между учетными записями (`su`).
