GNU/linux

Linux - программное ядро
Дистрибутив GNU/ linux общее определение операционных систем, используя Ядро Linux, готовых для конечной установки на пользовательское оборудование .

Дестрибутивы GNU/Linux

существует более 600 дестрибутивов, более половины из них поддерживаются в актуальном состоянии

существуют дистребутивы, разрабатываемый как при коммерческой поддержке: rad hat / fadora и т.д так и исключительно усилиями добровольцев: Arch linux/ ghentoo и т.д.
в состав многих дестрибутивов входит система установки, выполняющая те же функции что и в других современных ОС, некоторые дистрибутивы такие как Arch linux поддерживают только 1 ядро, средства для сборки ПО и собственно 
установщик, который в процессе выполнения собирает все необходимое ПО специально под устройство.
Структура каталогов:
структура всегда начинается с / - корневая папка.

enode - инедксные дескрипторы, есть у каждого файла

enodes являются уникальными на уровне разделов, можно иметь 2 файла с одинаковым enode, если они находятся в разных разделах

ls - li показывает все компоненты, дату установки, где находится, inode
кол-во enodes каждой файловой системы определяется при создании файловой системы.
Создание виртуальной машины:
Открываем Oracle VM Virtual box -> "создать" -> Вводим имя виртуальной машине, выбираем тип(Linux), а так же версия(Ubuntu 64-bit) -> далее выставляем оборудование: оперативная память: 4096, процессоры: 2,  Виртруальный жесткий диск: 25 гб. -> проверяем итог и нажимаем "Готово" -> Виртуальная машина создана.
