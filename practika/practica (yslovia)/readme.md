# Практика. Условия в Bash

## Что сделано

Запущен `script.sh`, который проверяет введённые данные и свойства файла.

- Скрипт читает число и сообщает, что оно положительное.
- По введённому имени `script.sh` сообщает, что это не каталог и что у файла есть право на чтение.
- Число в диапазоне от 1 до 5 принимается, на экране выводится `otlichno`.
