# Операционные системы и среды

Добро пожаловать на курс «Операционные системы и среды». Здесь операционная система рассматривается как среда выполнения программ, а практические навыки отрабатываются на Linux.

## О курсе

Курс построен по принципу «от понимания к практике»: каждая тема сопровождается заданиями. Материалы, конспекты и результаты работ ведутся в одном Git-репозитории.

## Как устроена работа

- **Единый репозиторий.** Заметки и результаты практик лежат в одном Git-репозитории. История коммитов — часть курса.
- **Сквозная практика.** Настройки, сделанные в начале курса, используются в следующих заданиях.

## Как устроен репозиторий

- `teory` — конспекты и материалы по теории.
- `homework` — домашние работы. В каждой папке есть `readme.md` с кратким отчётом и папка `screenshots` со снимками экрана. Картинки из `screenshots` вставлены в отчёт.
- `practika` — работы с пары. Оформлены так же: `readme.md` и папка `screenshots`, снимки подключены в отчёт.

Отчёт ссылается на снимок так:

```markdown
![Что видно на снимке](screenshots/01-nazvanie.png)
```
